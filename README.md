# Yemot Streaming API

מאגר קישורי סטרימינג לדוגמה, עם נקודת API המיועדת לחיבור למערכת ימות המשיח.

## קישורי הסטרימינג שהוגדרו

| שלוחה / פרמטר | תיאור | פורמט |
|---|---|---|
| `?item=1` | מוזיקת רקע באיכות גבוהה | MP3, סטריאו 128 kbps |
| `?item=2` | מוזיקת רקע חסכונית לשיחות | MP3, מונו 32 kbps |
| `?item=3` | מוזיקת רקע בפורמט HLS | HLS |

הקישורים הם זרמי בדיקה של Radio Mast, שמשמיעים מוזיקה ברישיון המתואר באתר המקור. אלה אינם שידורי רדיו ישראליים. המקור מציין שהזרמים זמינים ללא תשלום לשימוש אישי ומסחרי:
https://www.radiomast.io/reference-streams

## פריסה ב-Vercel

1. ייבא את המאגר הזה ל-Vercel.
2. פרוס את הפרויקט.
3. בדוק את `https://YOUR-PROJECT.vercel.app/api/yemot`.
4. בדוק את `https://YOUR-PROJECT.vercel.app/api/yemot?item=1`, וכן `item=2` ו-`item=3`.

## חשוב לפני חיבור לקו פעיל

ה-API מחזיר תשובת טקסט פשוטה בפורמט ימות המשיח. יש לבדוק במערכת שלך שפקודת `playfile=` נתמכת עבור כתובת סטרימינג חיצונית, ושפורמט הזרם נתמך במערכת. אם המערכת דורשת פקודת השמעה אחרת או קובץ שמע ולא זרם חי, יש להתאים את התשובה בהתאם.

הזרמים נמצאים בשליטת ספק חיצוני ועשויים להשתנות או להפסיק לעבוד.
