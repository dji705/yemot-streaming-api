# Yemot Streaming API

תפריט API לבחירת תחנת רדיו ישראלית דרך מערכת ימות המשיח.

## בחירת תחנה

הכתובת:
`https://yemot-streaming-api.vercel.app/api/yemot`

השרת מבקש מהמתקשר להקיש מספר בין 1 ל־8, ואז מחזיר לימות את הפעולה `music_on_hold=<שם תחנה>`.

| מקש | תחנה |
|---|---|
| 1 | כאן ב |
| 2 | כאן גימל |
| 3 | כאן 88 |
| 4 | גלגלצ |
| 5 | גלי צה"ל |
| 6 | רדיו 103FM |
| 7 | רדיו תל אביב |
| 8 | רדיו ירושלים |

## הגדרה בשלוחת ימות

בקובץ `ext.ini`:

```ini
type=api
api_link=https://yemot-streaming-api.vercel.app/api/yemot
```

## חשוב מאוד לפני הבדיקה

הפקודה `music_on_hold=` משתמשת בשם מוזיקה/שידור שכבר מוגדר במערכת ימות; היא **לא** מנגנת כתובת URL חיצונית באופן ישיר. יש לוודא שכל אחד מהשמות בטבלה מוגדר וזמין בחשבון שלך בשירות השידורים של ימות. אם השמות לא הוגדרו בחשבון, התפריט יכול לפעול אך השמע לא יתחיל.

תיעוד מודול API של ימות המשיח:
https://f2.freeivr.co.il/topic/56

## בדיקה בדפדפן

- תפריט: `https://yemot-streaming-api.vercel.app/api/yemot`
- בדיקת בחירה 1: `https://yemot-streaming-api.vercel.app/api/yemot?Station=1`
- בדיקת בחירה 4: `https://yemot-streaming-api.vercel.app/api/yemot?Station=4`

בדיקת הדפדפן מאמתת את טקסט התשובה בלבד. את השמעת התחנה עצמה יש לבדוק בשיחת טלפון לאחר הגדרת השמות במערכת ימות.
